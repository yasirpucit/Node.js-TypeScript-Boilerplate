# Node.js TypeScript Boilerplate

A minimal and efficient Node.js project template using TypeScript. This boilerplate provides a basic structure for building scalable and maintainable server-side applications.

## Features

- **TypeScript**: Type safety and enhanced development experience.
- **Nodemon**: Automatic server restarts during development.
- **Production Ready**: Build and run your application with optimized JavaScript files.
- **Custom Scripts**: Easy-to-use npm scripts for development, build, and production.

## Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/yasirpucit/Node.js-TypeScript-Boilerplate.git
   cd node-typescript

2. Install Dependencies

   ```bash
   npm install

3. Usage

   Development

   ```bash
   npm run dev
   ```

   Build

   ```bash
   npm run dev
   ```
   
   Production

   ```bash
   npm run prod
   ```

   Start

   ```bash
   npm run start
   ```

4. Project Structure

   ```bash
   src/
    ├── index.ts        # Main entry point of application
    └── ...             # Additional application files
    dist/               # Compiled JavaScript files (generated after build)
   ```

5. Scripts

   ```bash
   npm run dev: Start the development server with Nodemon.
   npm run build: Compile TypeScript into JavaScript.
   npm run prod: Build the project and start the production server.
   npm run start: Start the server using ts-node.
   ```

6. Requirements

   ```bash
   Node.js >= 14.x
   npm >= 6.x
   ```
